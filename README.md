# 听会台 · Mac 独立版

实时字幕、译文、要点、纠错与初步核查；会后全文和总结保存在自己的 Mac。无需租服务器，不关联 Aaron 的电脑或会议资料。

**让你的 AI 安装：把本仓库链接发给能操作你 Mac 的 Claude Code / Codex，并说「请按 AI-SETUP.md 安装听会台」。**

- [给 AI 的安装入口](AI-SETUP.md)
- [你需要准备什么：语音转写和 AI 助手](RAY.md)
- [下载完整源码安装包](tinghuitai-desktop-v0.3.0.zip)

本仓库用 ZIP 分发完整源码与安装器，程序不在仓库根目录。不要直接在根目录运行 npm；先解压安装包，再按其中的 AI-SETUP.md 操作。GitHub 的 Code → Download ZIP 会多套一层，仍需解压里面的听会台安装包。

**只需两项：**语音转写（火山流式语音识别，官方列出 20 小时试用，资格和有效期以控制台为准）＋一个帮你总结的 AI。

AI 这项从 0.3.0 起不一定要申请 API Key：设置页会自动看你这台 Mac 上有没有装 **Codex**（ChatGPT 账号）或 **Claude Code**（Claude 订阅），装了就点一下按钮，它当场试跑一次，通了就直接用你已有的额度，不用另外注册、不用充值。没装的话，第 ② 条把 DeepSeek 的注册、充值、拿 Key 拆成三步写清楚了，每步都有直达链接。公司自建网关填同样三个框。

首次安装可能下载 Node 与 npm 依赖；安装包本身约 140 KB，不含大型语音模型。火山语音和模型 API 按供应商计费。默认本机归档；飞书是可选项。账号登录、服务开通及麦克风权限需要本人完成。

已验证：隔离测试、Mac 上 bash 安装、本机全文归档和下载；尚未在 Ray 的设备或 API 账户上验收。正式开会前完成 30 秒试录。手机独立录音不属于本版。

更新说明：[RELEASE-0.3.0.md](RELEASE-0.3.0.md)（2026-09-10：免 API Key 接入向导、录音管理看板、补充材料与图片理解、要点按结论自动分组、语种自动识别与三种新语言、20 余项修复）。
