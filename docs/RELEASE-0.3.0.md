# Meeting LiveMate 0.3.0

## 这版最大的变化：不用申请 API Key 也能用

打开设置页，第 2 步「谁来帮你总结」会自动看这台电脑上有没有装 Codex 或 Claude Code。
装了就点一下按钮，它当场试跑一次，通了就写进配置——用的是你 ChatGPT 账号或 Claude 订阅的额度，不用另外申请、不用充值。

没装也没关系，第 ② 条把 DeepSeek 的注册、充值、拿 Key 三步拆开写清楚了，每一步都有直达链接，五分钟能弄完。
公司自建网关或别的服务商填同样三个框。

## 会中

- **要点自动分组**：不再是一条条平铺。每隔几句会把要点归成几个大标题，编号 1a / 1b / 1c，标题写的是结论而不是话题名，连着读就是这场会的梗概。原来的卡片和点击改删都没变。
- **补充材料**（原「我的笔记」）：文字和图片在同一个输入框里。截图可以直接 ⌘V 粘进来，也能拖文件或点选。点「发送给助手看」，助手会真的打开每张图看一遍，给出描述和一句整体判断，随会议一起归档。
- **说什么语言自己认**：默认「自动识别」，不用先选。中文看字符，其他语言看高频词，判出来会告诉你并按它识别。判错了在设置里手动定住即可。
- **新增印尼语、巴西葡语、西班牙语**：这三种在选单里单列一组，标着「会中字幕仅供参考」——实测火山对它们还听不准，所以录音会在会后用本机模型重新转写一遍，那一遍是准的。
- **按钮再按一次就关**：补充材料、会议档案、录音管理、本场纪要、更多，都不用再去点右上角的叉。
- **要点不再被自动刷新拖到底**：你翻到哪就停在哪，只有换一场会议才回到最新。
- **底栏多了「继续上一场」**：录音中途关了页面，提示条划掉也能从这里回来接着录。

## 会后

- **录音管理看板**（原「历史场次」）：一场一张卡，按周分组，能按来源和状态筛。卡上是主题、日期、时长、来源、状态，按钮是打开、重新整理、删除。
- **删除进回收区**：只删这台电脑上的记录，30 天内可以从「最近删除」里恢复。飞书文档一律不碰。正在录或正在整理的场次删不掉。
- **回看页重排**：跟会中界面同一套从左到右的排版——逐字稿、要点、待核查；下面一排是本场总结、待办确认、问助手。
- **待办浓缩**：一场会几十上百条要点，压成最多 5 条「我要去干嘛」，每条带一句会议依据，可以直接建成待办。

## 修的问题

这版修了 20 多个问题，其中影响数据安全的几条：删除接口的会议编号没做校验（构造路径能碰到别的文件）、恢复失败后重启会把已恢复的文件再删一次、删除时漏掉几类同场文件、会中分组失败会连环调用模型。

## 升级

覆盖安装即可，会议数据在 `~/Library/Application Support/Tinghuitai`，不受影响。
