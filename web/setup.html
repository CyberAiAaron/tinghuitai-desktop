开通大模型流式语音识别后，在应用详情里复制下方两项。这里填语音应用的凭证，不是火山方舟模型 Key，也不是通用云账号 AK/SK。

2. 谁来帮你总结

三条路，挑一条就行。推荐第一条：如果你电脑上已经装了 Codex 或 Claude，直接用它，不用申请、不用付钱。

① 用我电脑上已经装好的 AI检测中…
Codex 用你的 ChatGPT 账号，Claude Code 用你的 Claude 订阅。都不需要另外申请 Key，也不额外花钱。
② 用 DeepSeek（没装上面那些就选这条）
一次性设置，大约五分钟，之后就不用管了。按顺序做这三步：
  1. 打开 DeepSeek 注册页，用手机号注册。
  2. 在 充值页 充 10 元，够用很久。
  3. 在 API Keys 页 点「创建」，把那串 sk- 开头的字复制下来，粘到下面。
③ 公司给了我接口
公司自建网关或别的服务商，把地址、模型名和 Key 填进上面②的三个框即可。
