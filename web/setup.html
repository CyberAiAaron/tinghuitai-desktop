准备好，就能开始听会

只需连接语音和模型服务。会议保存在这台 Mac；语音会发给火山，文字会发给你配置的模型服务。

1. 语音转写

打开火山语音控制台 ↗
开通大模型流式语音识别。这里填语音应用的凭证，不是火山方舟模型 Key，也不是通用云账号 AK/SK。

2. 翻译、总结和初步核查

创建 DeepSeek API Key ↗
需要可用 API 额度；聊天会员不是 API 余额。也可以使用获授权的兼容服务。

使用公司接口或调整模型

已配置的密钥不会回显；留空保留原值。只有你新填写的内容会在本机保存。

进入听会台

首次使用先试录 30 秒：确认自己和对方都有字幕，再结束并查看会议档案。API 调用可能计费。核查结果是模型初判，未经联网证据验证。
